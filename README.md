# InDesign Book Studio

A Windows WPF desktop application for writing and designing books.

Features: multi-page books, page navigation, rich text editing, fonts, sizes, bold/italic, alignment, zoom, title/author metadata, and save/load IDBOOK project files.

Run on Windows with .NET 8 SDK using dotnet restore and dotnet run.

Roadmap: text frames, image placement, master pages, rulers/guides, columns, paragraph styles, templates, PDF export, and undo/redo.
